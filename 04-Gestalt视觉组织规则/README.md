# 04-Gestalt 视觉组织规则

Gestalt（格式塔）视觉组织研究关注我们如何把视觉元素组织成群组和整体，以及如何从背景中辨认主体。

首版拟收录 13 个条目。Wagemans 等人的综述列举了 7 个经典分组线索和 4 个后续线索，本专项另纳入图形与背景、良好形态两项。13 是本专项的编排数量，文献中的计数随收录范围和细分程度而变化。[视觉组织综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/) · [理论综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC3728284/)

| 条目 | 定义 | 案例分析与设计实践 |
| --- | --- | --- |
| 接近律 Proximity | 距离较近的元素倾向于被读成一组。 | 来图右侧拉开中间两列的间距，16 个点读成两组。让注释靠近所属图形，组间留白大于组内。若空间位置编码数据，用分隔或标签强调分组。 |
| 相似律 Similarity | 共享形状、颜色、大小、纹理或朝向的元素倾向于归组。 | 来图用圆与三角形区分形状。黄色倒三角同时共享颜色和朝向。跨图保持同一类别的编码一致，并检查灰度下能否区分。 |
| 良好连续 Good Continuation | 排列在平滑路径上的线段或标记倾向于被读成连续整体。 | 用交叉折线作示意。在线末直接标注系列，检查交叉后是否会沿错线。缺测区间应有清晰提示。 |
| 闭合律 Closure | 在轮廓线索足够时，有缺口的边界仍可能被感知为完整形状。 | 来图的橄榄球被两道浅色斜带切开，外轮廓和球缝仍支撑辨认。在最小使用尺寸检查缺口和关键轮廓。 |
| 共同命运 Common Fate | 一起向同一方向运动的元素倾向于归组。 | 来图标题为 Synchrony，正文描述同向运动。静态画面直接可见的是相同朝向，也存在接近线索。动态示例可让两组点向不同方向移动，检验能否辨认组别。 |
| 对称性 Symmetry | 围绕轴线互为镜像的部分倾向于被组织为一个整体。 | 来图右侧两块颜色共用中轴，外轮廓读成一个大三角形。镜像布局可用于并列比较，比例与基线应对应数据。 |
| 平行性 Parallelism | 平行排列的线段或边界倾向于被看成一组。 | 用并列路线作示意。检查颜色和标注是否足以区分互相平行但各自独立的路线。 |
| 时间同步 Synchrony | 在同一时刻发生视觉变化的元素倾向于归组。 | 动态示例可让不同位置的关联标记同时改变明暗，并用错时版本对照。初稿中用户提供的静态同向三角图不能直接演示时序变化。 |
| 共同区域 Common Region | 落在同一可辨识区域内的元素倾向于归组。 | 用浅色底块容纳同一阶段的多个事件。检查跨边界的标签是否容易被错分。[Palmer](https://pubmed.ncbi.nlm.nih.gov/1516361/) |
| 元素连接 Element Connectedness | 由线或其他可见连接件连起来的元素倾向于被识别为有关联。 | 用组织图连线标明关系。检查线端和交叉处是否会让读者误认连接对象。 |
| 均匀连通 Uniform Connectedness | 视觉属性一致或平滑变化的连续区域容易被看作一个视觉单元。 | 用连续填色的覆盖区作示意。检查颜色或纹理突变是否让读者读出意外边界。[Palmer 与 Rock](https://pubmed.ncbi.nlm.nih.gov/24203413/) |
| 图形与背景 Figure–Ground | 视觉系统会把共同边界归给其中一侧，将其看成主体，另一侧看成背景。 | 来图右侧可在两张侧脸与中间浅色形状之间切换。地图上的数据标记应能从底图中辨认，重点轮廓也要清楚。 |
| 良好形态 Prägnanz | 在给定条件下，视觉系统倾向于形成更规则、稳定、连贯的整体组织。 | 来图的椅子展示设计上的简化，保留了靠背、扶手和坐垫。用小尺寸测试识别率。可另补同一刺激存在多种组织方式的知觉案例。 |

时间同步还可用同时变化与错时变化的版本比较。[Palmer、Brooks 与 Nelson](https://palmerlab.berkeley.edu/pdf/PalmerBrooks%26Nelson.pdf)

## 案例与实践记录

新增案例依次记录原图及来源、可观察的变化、涉及的规则及其相互作用、读图任务、改版方案和验证结果。上表中非来图示例为设计示意，实践建议待实际案例验证。

七张来图纳入首批案例分析。相似律图的大小示例同时改变了间距与对齐，朝向示例也改变了位置。分析时应记录这些共同变化，若需验证单一线索，可一次只改变一个属性。
