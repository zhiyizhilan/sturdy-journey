# 03-ISOTYPE信息图

ISOTYPE（International System of Typographic Picture Education）是一种用标准化象形符号传达信息的设计方法。本专项记录 ISOTYPE 的设计原则、编码方法和案例。混合型、文字型／列表型、时间轴型等案例采用该方法时，可与本专项交叉引用。

## 案例收录依据

- 原作或可靠来源明确表明作品采用 ISOTYPE 时，记录出处。
- 当代案例若借用 ISOTYPE 的方法，记录图中证据。例如，用一组含义一致的象形符号表示对象，以固定单位重复排列同一符号来比较数量。记录单个符号代表的单位和不足一个单位时的处理方式。
- 若图中只有装饰图标，或只能确认使用了 ISO 标准图形符号，继续核实其编码规则或设计来源。ISO 标准图形符号的使用本身不足以作为本专项的收录依据。
